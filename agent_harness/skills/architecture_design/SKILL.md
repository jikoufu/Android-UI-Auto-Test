# 架构设计

读取当前任务需求与项目政策，检查现有调用方和配置入口。在 `design.md` 记录本次需要改变的模块、接口、依赖方向和兼容方式。

优先复用已存在的边界；新抽象须解决当前具体问题。结构迁移要同时覆盖导入、资源定位、启动命令、测试收集和文档。识别需保留的数据与现有未提交变更。

为每条验收条件给出验证方法与所需环境。只把已经实现且检查过的能力标为可用；未来目录和接口明确说明尚未实现。设计不得自行扩大用户授权的发布或外部操作范围。
