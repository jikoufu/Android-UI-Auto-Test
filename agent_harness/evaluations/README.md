# 离线评估

运行 `python -m agent_harness.evaluations.validate` 可检查工作流引用、步骤顺序、技能元数据与未执行模板；追加 `--task tasks/任务编号` 检查具体任务。此工具只读取文件，不运行工作流或记录里的命令。

`unit_tests/agent_harness/` 用临时文件和模型输入验证失效路径，包括不存在的技能、依赖倒序、越界引用、没有执行证据却声称通过、完成状态与结果矛盾。

修改技能后还应审阅一个实际适用请求：路由是否选择正确流程、是否遵守用户范围、是否使用项目政策而非内置业务假设、是否如实区分自查和独立验证。当前离线测试不代表已完成 Codex、Claude、DeepSeek 的端到端执行评估。
